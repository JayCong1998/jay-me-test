# 杰迷试炼 PRD

> 本文档只记录产品目标、功能范围、业务规则和用户流程。技术选型、接口和模块实现见 [TECH.md](TECH.md)；运行时架构、Round 生命周期和安全边界见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 1. 产品定位

**杰迷试炼** 是面向周杰伦粉丝的移动端答题 H5。用户可以通过经典随机答题、专辑闯关和无尽深渊三种玩法检验自己的杰迷水平，获得等级结果、电子证书、历史记录和排行榜排名。

## 2. 目标用户

| 用户类型 | 典型诉求 |
| --- | --- |
| 游客用户 | 低门槛体验经典模式，答完后查看等级和证书。 |
| 注册用户 | 保存成绩、查看个人记录、参与排行榜、挑战专辑和深渊。 |
| 核心杰迷 | 按专辑逐关挑战，追求更高正确率和更长深渊 streak。 |
| 运营管理员 | 维护题库，查看用户、记录和运营概览。 |

## 3. 产品范围

### 3.1 用户端 H5

- 首页展示产品入口、三种玩法入口和全局统计概览。
- 经典模式允许游客和登录用户游玩。
- 专辑闯关、无尽深渊、个人记录和排行榜需要登录。
- 答题页提供题目、选项、进度、计时、即时反馈和退出确认。
- 结果页展示等级、得分、正确率、用时、击败率、复活使用情况和专辑通关结果。
- 证书页根据本局结果生成可保存、可分享的电子证书。
- 我的页面展示登录身份、主题切换和个人答题记录。

### 3.2 管理端

- 管理员登录使用独立登录态。
- Dashboard 查看题目、用户、答题记录等运营概览。
- 题库管理支持列表筛选、详情查看、新增、编辑和选项答案分布重平衡。
- 用户管理支持按关键词查询注册用户。
- 记录管理支持按关键词、模式、时间范围筛选答题记录。

### 3.3 暂不承诺范围

- AI 问答当前没有可用用户端入口和后端控制器，不作为当前产品功能承诺。
- 好友对战、每日挑战、PWA 离线、听歌识曲等仍属于后续方向。

## 4. 核心玩法

### 4.1 经典模式

- 游客可玩，登录用户也可玩。
- 每局随机抽取 20 道题。
- 当前抽题规则为 EASY 60%、MEDIUM 40%，题目顺序随机。
- 用户逐题作答，每题提交后立即展示对错、正确答案和解析。
- 固定题量模式必须答完整局后才能结算。
- 结算后按正确率生成等级、保存服务端记录，并可生成证书。

### 4.2 专辑闯关

- 仅登录用户可进入。
- 专辑按发行时间顺序排列，当前枚举包含 16 张录音室专辑：`Jay` 到 `太阳之子`。
- 新用户默认解锁第一张专辑 `Jay`。
- 每关从指定专辑题库中抽取 20 道题。
- 正确率达到 80% 即通关，并解锁下一张专辑。
- 专辑进度记录最佳答对数、挑战次数、首次通关时间和最近挑战时间。
- 结果页展示是否通关、是否刷新最佳成绩、是否解锁下一专辑。

### 4.3 无尽深渊

- 仅登录用户可进入。
- 开局返回首批 5 道题，前端在批次完成后加载下一批。
- 用户必须按服务端题目顺序作答。
- 答对累加 streak，答错后进入失败态。
- 每局有 1 次续命机会。首次答错且仍有续命时，不展示正确答案和解析；续命后重答当前题。
- 续命用完后再次答错，结算当前 streak。
- 深渊等级按连续答对数计算，而不是按固定题量正确率计算。

## 5. 等级与成绩

### 5.1 经典等级

经典模式按正确率百分比划分等级：

| 正确率 | 等级 |
| --- | --- |
| 0% - 29% | 路人粉 |
| 30% - 49% | 初级杰迷 |
| 50% - 69% | 中级杰迷 |
| 70% - 89% | 高级杰迷 |
| 90% - 100% | 终极杰迷 |

### 5.2 专辑等级

专辑模式按正确率百分比划分等级：

| 正确率 | 等级 |
| --- | --- |
| 0% - 59% | 专辑新生 |
| 60% - 79% | 专辑听友 |
| 80% - 100% | 专辑大师 |

### 5.3 深渊等级

深渊模式按 streak 划分等级：

| streak | 等级 |
| --- | --- |
| 0 - 2 | 深渊游客 |
| 3 - 5 | 深渊探索者 |
| 6 - 10 | 深渊战士 |
| 11 - 20 | 深渊骑士 |
| 21 - 30 | 深渊领主 |
| 31 - 50 | 深渊霸主 |
| 51+ | 深渊之神 |

### 5.4 击败率

击败率按同玩法登录用户的历史最佳成绩计算：当前分数高于多少用户的最佳分数，就显示击败多少比例的玩家，最高显示 99.99%。

## 6. 排行榜

排行榜仅登录用户可查看，分为三类：

| 榜单 | 排序口径 |
| --- | --- |
| 经典榜 | 每个用户取经典模式最佳记录，按答对数降序、用时升序、创建时间升序排序。 |
| 专辑榜 | 每个用户每张专辑取最佳记录，按已通关专辑数、专辑总成绩、总用时排序。 |
| 深渊榜 | 每个用户取最高 streak，按 streak 降序、用时升序、创建时间升序排序。 |

## 7. 用户流程

### 7.1 游客经典答题

```text
进入首页 -> 点击经典模式 -> 进入答题页 -> 逐题作答 -> 提交结果
  -> 查看等级结果 -> 查看证书 -> 可选择登录/注册参与排行
```

### 7.2 登录用户专辑闯关

```text
登录 -> 首页点击专辑闯关 -> 查看专辑列表
  -> 选择已解锁专辑 -> 完成 20 题 -> 查看通关结果
  -> 通关后挑战下一专辑，未通关可重试
```

### 7.3 登录用户无尽深渊

```text
登录 -> 首页点击无尽深渊 -> 开始首批题目
  -> 答对继续推进并按批次预加载 -> 答错
  -> 可续命则重答当前题，不可续命则结算 streak
```

### 7.4 管理员运营

```text
进入管理端 -> 管理员登录 -> 查看 Dashboard
  -> 维护题库 / 查询用户 / 查询答题记录
```

## 8. 边界与异常

| 场景 | 产品处理 |
| --- | --- |
| 未登录访问专辑或深渊 | 引导登录，登录后返回目标入口。 |
| 未登录查看排行榜或个人记录 | 展示登录引导。 |
| 答题中刷新页面 | 前端答题状态丢失，用户需回首页重新开始。 |
| Round 过期或不存在 | 提示重新开始本局。 |
| 固定题量模式未答完就结算 | 服务端拒绝提交。 |
| 深渊未失败就结算 | 服务端拒绝提交。 |
| 网络异常或提交失败 | 前端提示重试；结果提交失败时可使用本地结果兜底展示。 |
| 题库不足 | 服务端返回错误；运营需要补充题库。 |

## 9. 成功指标

| 指标 | 目标 |
| --- | --- |
| 首页到开始答题转化率 | 80% 以上 |
| 固定题量模式完答率 | 85% 以上 |
| 注册转化率 | 15% 以上 |
| 人均复玩次数 | 2 次以上 |
| 专辑模式解锁 2 张以上专辑用户占比 | 40% 以上 |
| 证书保存或分享率 | 30% 以上 |
