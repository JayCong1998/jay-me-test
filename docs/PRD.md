# 杰迷结业考试 (jay-me-test) 产品需求文档

> 版本：v2.0 | 日期：2026-07-17 | 状态：迭代开发中

---

## 1. 产品概述

### 1.1 产品定位

**一句话描述**：一个面向周杰伦粉丝的 H5 答题应用，用户完成 10 道随机单选题后获得 5 级杰迷等级鉴定和专属电子证书，支持社交分享裂变。V2 新增用户系统、专辑闯关模式、排行榜和 AI 问答。

### 1.2 产品目标

| 目标 | 衡量指标 | 预期值 |
|------|----------|--------|
| 低门槛进入 | 首页→答题转化率 | > 80% |
| 碎片化娱乐 | 单局平均耗时 | 2-3 分钟 |
| 社交传播 | 证书分享率 | > 30% |
| 内容质量 | 题目准确率（用户反馈） | 100%（零错误） |
| 复玩留存 | 人均复玩次数 | > 2 次 |
| 用户注册 | 答题用户→注册转化率 | > 15% |

### 1.3 目标用户

| 用户画像 | 特征 | 核心诉求 |
|----------|------|----------|
| **路人粉** | 听过热门歌曲，对周杰伦了解不深 | 娱乐消遣，测试自己的粉丝"段位" |
| **资深杰迷** | 熟悉所有专辑和歌词，自认"铁粉" | 身份认证，证明自己是真正的杰迷；挑战全部 15 张专辑 |
| **社交分享者** | 喜欢在朋友圈/微信群晒成果 | 获取社交货币，引发好友互动和跟风 |
| **竞技型玩家** | 追求高分和排名 | 上榜、超越他人、解锁全部专辑 |

### 2.2 模块 1：用户系统

**用户故事**：作为一个粉丝，我希望注册账号后能保存答题记录、解锁专辑进度、参与排行榜。

**功能点**：

| ID | 功能 | 优先级 | 描述 |
|----|------|--------|------|
| F1.1 | 邮箱注册 | P0 | 邮箱 + 密码 + 昵称注册，密码 BCrypt 加密存储 |
| F1.2 | 邮箱登录 | P0 | 邮箱 + 密码登录，返回 JWT 令牌（有效期 7 天） |
| F1.3 | 登录态保持 | P0 | Token 持久化到 localStorage，7 天内免登录 |
| F1.4 | 游客兼容 | P0 | 未登录仍可完整答题（经典模式），登录后解锁专辑/排行/历史记录 |
| F1.5 | 登录引导 | P1 | 答题完成、查看排行榜、进入专辑模式时引导注册/登录 |

**交互规则**：
- 注册：邮箱格式校验 + 密码 ≥ 6 位 + 昵称 2-8 字
- 登录：邮箱 + 密码，成功后跳转回来源页面
- 路由守卫：`/albums`、`/leaderboard` 需登录，未登录跳转登录页

**价值**：为专辑进度、排行榜等需用户身份的功能提供基础，同时保持游客低门槛体验。

### 2.3 模块 2：答题核心玩法

**用户故事**：作为一个粉丝，我希望通过答题来测试自己对周杰伦的了解程度，每题答完能看到对错和解释。

**功能点**：

| ID | 功能 | 优先级 | 描述 |
|----|------|--------|------|
| F2.1 | 随机抽题 | P0 | 经典模式：每局从题库随机抽取 10 道单选题（6 简单 + 4 中等），题目顺序打乱 |
| F2.2 | 逐题作答 | P0 | 一次展示一道题，用户选择 A/B/C/D 后点击提交 |
| F2.3 | 即时反馈 | P0 | 提交后立即显示 ✅正确 / ❌错误 + 正确答案 + 简短解析 |
| F2.4 | 答题进度 | P0 | 顶部显示当前题号（第 N/10 题）和进度条 |
| F2.5 | 计时器 | P0 | 顶部显示本轮答题已用时间（MM:SS 格式，仅展示不限制） |
| F2.6 | 复活机会 | P0 | 每局 1 次复活机会，答错时可选择使用，使用后该题可重答 |
| F2.7 | 退出确认 | P1 | 答题中点击退出，弹窗二次确认 |

**答题流程**：

```
首页选择模式 → 开始答题 → 展示第 N 题 → 选择选项 → 提交答案 → 显示反馈
                             经典：随机 10 题              ├── ✅ 正确 → 下一题
                             专辑：指定专辑 10 题            └── ❌ 错误 → 可使用复活?
                                                                     ├── 是 → 重答该题
                                                                     └── 否 → 下一题
                                                              ↓
                                                      第10题完成 → 提交统计 → 结果页
```

**复活规则**：
- 只有答错时触发复活选项
- 使用复活后该题重置为未作答状态，用户重新选择
- 每局仅 1 次，使用后按钮消失
- 复活后再次答错不可再复活

**价值**：承载产品核心玩法，单局 2-3 分钟适配碎片化场景；即时反馈保障答题爽感；复活机制提升完答率。

### 2.4 模块 3：等级鉴定结果

**用户故事**：作为一个粉丝，我希望答完题后能看到我的"杰迷等级"，知道自己是什么水平的粉丝。

**功能点**：

| ID | 功能 | 优先级 | 描述 |
|----|------|--------|------|
| F3.1 | 等级匹配 | P0 | 根据答对题数匹配 5 级杰迷等级 |
| F3.2 | 等级展示 | P0 | 展示称号（大字）、等级描述、得分（X/10） |
| F3.3 | 数据面板 | P0 | 展示正确率、答题用时、"击败 X% 的杰迷" |
| F3.4 | 复活标记 | P1 | 显示本轮是否使用了复活机会 |
| F3.5 | 全局统计 | P1 | 首页展示总参与人数等概览数据 |
| F3.6 | 专辑结果 | P0 | 专辑模式下额外展示：专辑名、通过/未通过、是否新纪录、解锁下一张提示 |

**5 级杰迷等级体系**：

| 答对 | 等级 | 称号 | 描述 |
|------|------|------|------|
| 0-2 | 路人粉 | 🌱 路人粉 | 刚刚路过，杰伦的歌还等你发现 |
| 3-4 | 初级杰迷 | 🎤 初级杰迷 | 入门粉丝，继续加油解锁更多杰伦冷知识 |
| 5-6 | 中级杰迷 | 🎧 中级杰迷 | 资深听友，离骨灰粉只差一张专辑的距离 |
| 7-8 | 高级杰迷 | 🏆 高级杰迷 | 铁粉认证，演唱会前排选手就是你 |
| 9-10 | 终极杰迷 | 👑 终极杰迷 | 你就是杰伦的"编外制作人"！无可挑剔 |

**百分位计算**：`击败比例 = (得分低于当前用户的游戏记录数 / 总游戏记录数) × 100%`

**价值**：兑现"等级考试"的核心产品价值，给用户明确身份认证反馈，是激发分享行为的核心动因。

### 2.5 模块 4：电子证书与分享裂变

**用户故事**：作为一个粉丝，我希望把我获得的等级分享到朋友圈/微信群，让朋友看到我的"杰迷认证"。

**功能点**：

| ID | 功能 | 优先级 | 描述 |
|----|------|--------|------|
| F4.1 | 证书生成 | P0 | 生成带用户昵称 + 等级称号的专属电子证书 |
| F4.2 | 证书预览 | P0 | 证书页实时预览证书效果 |
| F4.3 | 保存图片 | P0 | 支持保存证书图片到手机相册（Canvas → PNG 下载） |
| F4.4 | 一键分享 | P0 | 分享按钮，调起系统分享面板/复制文案/引导截图 |
| F4.5 | 默认文案 | P0 | 预置分享文案："我在杰迷结业考试中获得了「{等级称号}」称号！你也来测测你是几级杰迷？" |

**分享三级降级策略**：

```
点击分享
  ├── Tier 1: Web Share API（iOS Safari / Android Chrome）
  │   └── 弹出系统原生分享面板 → 选择微信/朋友圈/微博等
  │
  ├── Tier 2: Clipboard API（不支持 Web Share 的现代浏览器）
  │   └── 复制分享文案到剪贴板 → Toast 提示"已复制，去粘贴给朋友吧"
  │
  └── Tier 3: 手动引导蒙层（微信内置浏览器等限制环境）
      └── 底部弹出引导层 → "点击右上角 ... → 分享给朋友"
         或 "长按证书图片保存后分享"
```

**证书视觉规格**：
- 比例：9:16 竖版（1080 × 1520px）
- 背景：深色主题 + 金色点缀，带周杰伦相关视觉元素水印
- 内容：昵称（金色）、等级称号（大字）、得分/正确率、考试日期

**价值**：作为社交传播的核心载体，验证产品自传播能力。

### 2.6 模块 5：基础题库储备

**用户故事**：作为产品运营者，我需要确保题库内容准确无误，覆盖不同类型的题目，让用户 2-3 次复玩不出现明显重复。

**功能点**：

| ID | 功能 | 优先级 | 描述 |
|----|------|--------|------|
| F5.1 | 题目录入 | P0 | 内置 70 道经事实校对的题目 |
| F5.2 | 题型分类 | P0 | 覆盖歌词填空/识别、专辑归属两类题型 |
| F5.3 | 难度分级 | P0 | 分简单（EASY）、中等（MEDIUM）两个梯度 |
| F5.4 | 专辑标注 | P0 | 每道题标注所属专辑（`album` 列），跨专辑/非录音室曲目为 NULL |
| F5.5 | 解析文案 | P0 | 每题附带简短解析说明（1-2 句话） |

**题目分布（70 题基准）**：

| 分类 | 简单 | 中等 | 小计 |
|------|------|------|------|
| 歌词类 (LYRICS) | 25 | 15 | 40 |
| 专辑归属 (ALBUM) | 20 | 10 | 30 |
| **合计** | **45** | **25** | **70** |

**题目质量标准**：
- 歌词内容必须与原版一致，不能有错别字或顺序错误
- 专辑归属必须有可靠来源（以官方发行信息为准）
- 每个选项需为合理干扰项，不能明显离谱
- 解析需标注歌曲名和发行年份

**价值**：保障答题内容的准确性与基础可玩性，避免错题损伤粉丝口碑。

## 5. 边界与异常处理

### 5.1 异常场景

| 场景 | 处理方式 |
|------|----------|
| 网络异常（接口超时） | Toast 提示"网络开小差了，请重试"，提供重试按钮 |
| 接口返回错误 | 展示服务端错误信息，提供重试 |
| localStorage 被清空 | 昵称/登录态丢失，重新设置/登录 |
| 答题中刷新页面 | 游戏状态丢失，回到首页重新开始 |
| 题库不足（专辑下 < 10 题） | 后端返回剩余全部题目，前端正常展示 |
| Canvas 生成失败 | 降级为纯文字分享（不附带图片） |
| Token 过期 | Sa-Token 返回 401，前端跳转登录页 |
| 未登录访问专辑/排行 | 路由守卫重定向到登录页 |
| 尝试访问未解锁专辑 | 后端返回 403 + 提示"请先通关 {上一张专辑名}" |

### 5.2 数据边界

| 字段 | 限制 |
|------|------|
| 昵称长度 | 2-8 个字符（中文/英文/数字/Emoji） |
| 邮箱 | 合法邮箱格式 |
