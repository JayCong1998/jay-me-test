# 管理端题目答案选项均衡设计

## 目标

在不改变任一题目正确答案内容的前提下，重新排列题库中题目的 A-D 选项位置，降低 `correct_option` 在四个字母上的分布偏差。

## 范围

- 新增仅管理员可调用的批量均衡接口。
- 在管理端题目管理页提供显式触发按钮和确认提示。
- 返回并展示执行后的 A-D 答案数量及被调整题数。

不新增数据库字段或迁移脚本；不修改已有 Round 缓存。已开始的 Round 已缓存其当时的答案位置，继续按开始时展示的题目校验。

## 处理规则

1. 读取全部题目并统计正确答案 A-D 的当前数量。
2. 将题目随机排序。若当前题目的答案位置属于较多的一侧，随机从当前较少的答案位置中选择目标位置。
3. 互换该题原正确位置与目标位置的选项文本，并将 `correctOption` 设为目标位置。
4. 每次成功调整后实时更新内存中的 A-D 计数；当最大、最小数量差不再大于 1 时停止调整。

该策略用随机题目顺序和随机并列目标位置保留随机性；其结果可能恰好接近平衡，但不把“精确均分”作为接口前置条件或单独的业务承诺。

## 接口

`POST /api/admin/questions/rebalance-options`

响应数据为 `QuestionOptionRebalanceResponse`：

```json
{
  "adjustedCount": 37,
  "answerDistribution": {
    "A": 50,
    "B": 49,
    "C": 50,
    "D": 49
  }
}
```

题库为空或已达到目标分布时返回 `adjustedCount: 0`，不会报错。

## 前端交互

题目管理页的“均衡答案分布”按钮在点击后使用浏览器确认框提醒该操作会批量重排全部题目选项。确认后按钮进入提交状态，调用接口，成功提示调整数量与最新分布并刷新列表；失败时复用页面已有错误提示。

## 验证

- 服务层单元测试验证交换选项后正确答案文本保持一致、答案计数向低位移动并返回最终分布。
- 管理端执行 TypeScript 与 Vite 生产构建，确保新增 API 与按钮通过类型检查。
