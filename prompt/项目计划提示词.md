我要做一个杰迷结业考试应用，叫 jay-me-test。
后端技术：
Spring Boot
MyBatis Plus
SQLite
Knife4j

前端技术：
Vue 3
Element Plus
Vue Router
Pinia
Axios
Vite

功能包括：
模块 1：免登进入与轻量身份
做什么：打开 H5 直达产品首页，无需登录授权；支持用户自定义昵称，用于后续生成证书，游玩数据本地存储。
价值：消除首次使用门槛，最大化访问到游玩的转化；昵称赋予证书身份专属感，不强制授权避免用户流失。
模块 2：答题核心玩法
做什么：单局固定 10 道单选题，从题库随机抽题；逐题作答，提交后即时显示对错与简短解析；单局设置 1 次复活机会。
价值：承载产品核心玩法，单局时长控制在 2-3 分钟，适配碎片化娱乐场景；即时反馈保障答题爽感；复活机制提升答题完答率。
模块 3：等级鉴定结果
做什么：答题结束后根据得分匹配 5 级杰迷等级，展示用户最终称号、正确率、答题用时、击败用户比例等数据。
价值：兑现 “等级考试” 的核心产品价值，给用户明确的身份认证反馈，是激发用户分享行为的核心动因。
模块 4：电子证书与分享裂变
做什么：生成带用户昵称、对应等级称号的专属电子证书；支持保存图片到本地，提供一键分享引导与默认分享文案。
价值：作为社交传播的核心载体，验证产品自传播能力；证书具备强社交货币属性，是冷启动阶段低成本获客的关键抓手。
模块 5：基础题库储备
做什么：内置 50-80 道经事实校对的题目，覆盖歌词、专辑归属两类基础题型，分简单、中等两个难度梯度。
价值：保障答题内容的准确性与基础可玩性，避免错题损伤粉丝口碑，支撑用户 2-3 轮复玩不出现明显题目重复。
