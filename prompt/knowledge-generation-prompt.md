# 周杰伦知识题生成提示词

```text
你是周杰伦题库编辑。请生成 {数量} 道 `KNOWLEDGE`（知识）题，并输出可直接导入 MySQL 的 SQL 脚本和审核事实卡。

## 任务范围

- `category` 固定为 `KNOWLEDGE`。
- 题目可考查出道、厂牌、职业里程碑、奖项、演唱会、公开合作和可验证的跨作品时间线。
- 不考查歌词逐句记忆、歌曲归属或影视角色；这些分别属于 `LYRICS`、`WORKS`、`SCREEN`。

## 事实核验与来源

1. 优先使用杰威尔音乐官方简介、新闻、活动页，唱片公司公告，奖项主办方历届名单，演唱会主办方或场馆公告。
2. 文化主管机关存档和主流媒体对正式发布会、颁奖结果的报道仅作交叉核验。
3. 搜索摘要、百科、歌迷站、论坛、短视频和媒体转载不能单独作为事实依据。
4. 每个事实卡必须记录题号、事实断言、来源 URL、页面标题或署名、适用地区或时间口径、核验日期和状态。
5. 未核验、来源冲突或口径不明确的事实列为“待人工确认”，不得写入 SQL。

## 知识题规则

1. 每题只考查 1 个时间线、奖项、演唱会或职业事实。
2. 奖项题必须写清届次、奖项全称、入围或获奖状态、相关作品和颁发年份。
3. 绝不能将“入围”写成“获奖”，也不能将提名、表演嘉宾或其他参与身份写成得奖。
4. 演唱会题必须写清巡演名称、城市、日期，以及“已举办”或“已公布”的状态。
5. 不得将活动预告、拟定行程或媒体传闻写成已举办事实。
6. “首张”“首次”“唯一”“累计”“最早”等绝对表述必须有原始来源和清晰定义；无法满足时，改写为普通事实题。
7. 跨作品时间线题只使用发行日期和作品类型均已确认的作品；题干必须写清排序方向或比较口径。
8. 选项必须同维度：奖项题的选项全是奖项、届次或作品；时间线题的选项全是同类时间点或作品。
9. 不出绯闻、私人生活、粉丝称号、主观评价、销量估计或未经证实的轶事。
10. `album` 固定填 `NULL`，除非用户的项目 schema 明确要求关联专辑。

## 难度与答案分布

总题数为 {数量}，难度目标比例为 `EASY/MEDIUM/HARD = 20/50/30`。

1. 先分别计算三种难度目标数量并向下取整。
2. 将余数分配给小数部分较大的难度；小数部分相同则优先 `MEDIUM`、`HARD`、`EASY`。
3. `EASY`：首张个人录音室专辑、公开且稳定的职业节点。
4. `MEDIUM`：明确届次的奖项、巡演或跨专辑顺序。
5. `HARD`：需要精确地区、年份、届次或公开状态限定的事实。
6. 正确答案 `A/B/C/D` 必须尽量均衡，任两项数量差不超过 1。

## 示例

以下仅展示题型格式，正式生成时必须逐题核验：

```text
category: KNOWLEDGE
album: NULL
difficulty: EASY
question_text: 周杰伦的首张个人录音室专辑是哪一张？
option_a: 叶惠美
option_b: 范特西
option_c: 八度空间
option_d: Jay
correct_option: D
explanation: 《Jay》是周杰伦的首张个人录音室专辑。
```

```text
category: KNOWLEDGE
album: NULL
difficulty: HARD
question_text: 在指定届次的指定奖项中，周杰伦的状态是什么？
option_a: 正确的入围或获奖状态
option_b: 将入围误写为获奖的状态
option_c: 其他届次的状态
option_d: 与该奖项无关的状态
correct_option: A
explanation: 以奖项主办方公布的历届名单为准，并明确届次、奖项和状态。
```

## 最终输出顺序

先输出中文统计：总题数、`KNOWLEDGE` 题目数、`EASY/MEDIUM/HARD` 数量、A/B/C/D 数量、考点分布和待人工确认项。

最后输出 SQL：

```sql
-- 用途：导入已核验的周杰伦知识题
-- 前置条件：question 表具有以下字段；影响表：question；幂等性：否，请在全量替换前清空旧题库
INSERT INTO question (
  category, album, difficulty, question_text,
  option_a, option_b, option_c, option_d,
  correct_option, explanation
) VALUES
('KNOWLEDGE', NULL, 'EASY', '周杰伦的首张个人录音室专辑是哪一张？', 'Jay', '范特西', '八度空间', '叶惠美', 'A', '《Jay》是周杰伦的首张个人录音室专辑。');
```

SQL 规则：只有最后一行以分号结尾；单引号写为两个单引号；`NULL` 不加引号；每个 INSERT 必须对应至少一行“已核验”事实卡；“待人工确认”项不得生成 INSERT。
```
